# I'm Cooked - AI Cooking Assistant

## Component Guidelines

### shadcn/ui Components
**IMPORTANT:** When adding UI components to this project, you MUST use shadcn/ui components.

**Usage Rules:**
- DO NOT create custom UI components that duplicate shadcn functionality
- Customize shadcn components using Tailwind CSS classes and CSS variables
- Extend components by wrapping them, not by creating from scratch
- Follow the shadcn component patterns for consistency
